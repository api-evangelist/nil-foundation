# =nil; Foundation

> =nil; is an Ethereum Layer 2 blockchain powered by zkSharding, providing horizontal scalability with built-in cross-shard communication and zero-knowledge proofs. Developers interact with the =nil; cluster through an Ethereum-style JSON-RPC API, the @nilfoundation/niljs TypeScript client, the =nil; CLI, and a Hardhat plugin. Generated by the API Evangelist enrichment pipeline from the public developer surface (no provider-published llms.txt found).

## APIs

- [=nil; JSON-RPC API](https://docs.nil.foundation/nil/references/json-rpc-api/): Ethereum-style JSON-RPC 2.0 API exposing ~25 methods for blocks, transactions/messages, accounts, contract calls, gas, shards, and event filters.
